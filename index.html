Contract Types

契約形態

ご依頼内容に応じて、以下の契約形態からご提案します。契約形態は、初回ヒアリング後にご依頼内容と必要な対応範囲を確認し、最適な方法をご提案します。

TYPE 01

準委任契約

調査、候補先の探索、問い合わせ、営業活動、関係者との調整など、業務の遂行そのものを委託いただく形態です。業務期間中の活動内容や進捗を共有しながら進めます。仕入れ先開拓、営業支援、継続的な外部担当業務に適しています。

TYPE 02

業務委託契約

調査報告書、候補先一覧、営業先リスト、取引条件の整理資料など、あらかじめ定めた業務内容や成果物を納品する形態です。スポット調査や、対応範囲を明確にした小規模案件に適しています。

TYPE 03

月額継続契約

月単位で契約し、仕入れ先の探索、販売先の開拓、営業先との連絡、定例報告、関係者との調整などを継続的に支援します。契約期間は1か月からご相談いただけます。翌月以降も継続する場合は、前月中に業務内容や対応方針を確認します。

TYPE 04

プロジェクト型契約

産地形成、複数生産者による供給体制づくり、新商品開発、地域産品の販路開拓など、目的・期間・関係者・成果物を定めて進める形態です。案件ごとに業務範囲、スケジュール、報告方法、費用を個別に設定します。

How it Works

ご依頼の流れ

01

お問い合わせ

仕入れ・営業・調査等、ご相談内容をお知らせください。

02

初回ヒアリング

商品、数量、地域、時期、価格、希望納期、現在お困りの点などを確認します。条件が決まっていない場合も、現状を伺いながら整理します。

03

対応方針・契約形態のご提案

スポット調査、業務委託、準委任、月額継続、プロジェクト型など、ご相談内容に合った契約形態と対応範囲をご提案します。

04

お見積り・契約内容の確認

業務内容、料金、契約期間、納期、報告方法、準備金、実費負担の範囲、キャンセル時の取り扱い等を記載した見積り・契約内容をご提示します。

05

ご契約・決済

内容にご同意いただいた後、契約を締結します。契約締結後、準備金または初回料金をご請求し、入金確認後に業務を開始します。

06

準備・調査・開拓

初期準備を行ったうえで、候補先の調査、関係先への問い合わせ、営業活動、条件確認等を実施します。

07

進捗共有・結果報告

必要に応じて途中経過を共有し、候補先、条件、数量、価格、対応可能時期等を整理して報告します。

08

継続・追加支援

取引に向けた追加確認、現地訪問、継続営業、産地形成支援等が必要な場合は、別途内容と費用をご提案します。
